# ⏱️ Stopwatch Web Application

A simple and responsive Stopwatch Web Application built using **HTML**, **CSS**, and **JavaScript**.

This project allows users to start, pause, resume, reset the stopwatch, and record lap times. It features a clean and modern user interface with a stopwatch icon and lap history section.

---

## 🚀 Features

- Start Stopwatch
- Pause Stopwatch
- Resume Stopwatch
- Reset Stopwatch
- Record Lap Times
- Responsive Design
- Clean and Modern UI
- Built with Pure JavaScript (No Libraries)

---

## 🛠️ Technologies Used

## 🎯 Functionality

### Start Button
- Starts the stopwatch.
- Changes to Pause while running.
- Changes to Resume when paused.

### Lap Button
- Saves the current stopwatch time.
- Displays lap records below the stopwatch.

### Reset Button
- Stops the stopwatch.
- Resets timer to `00:00:00`.
- Clears all lap records.
